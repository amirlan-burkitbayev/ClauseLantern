# ClauseLantern

Бесплатный инструмент с открытым кодом для первичной проверки договоров на компьютере пользователя. Локальная модель Ollama извлекает ключевые условия и определения, затем сравнивает их с правилами проверки. Для каждого замечания можно сверить цитату с оригиналом и выгрузить отчёт в Word. [Лицензия MIT](LICENSE).

### Запуск в три шага

1. Скачайте репозиторий, установите Python 3.12 и Ollama. В каталоге проекта создайте окружение командой `python -m venv .venv`, затем установите зависимости через `python -m pip install -r requirements.txt`, используя Python из этого окружения. [Команды для Windows и macOS](README.md#quickstart--3-steps).
2. Запустите Ollama с отключёнными облачными функциями и скачайте модель командой `ollama pull qwen3:4b`. Для установки пакетов и скачивания модели нужен интернет. [Команды настройки Ollama](README.md#2-start-local-ollama-and-install-a-model).
3. Запустите `python -m streamlit run app.py` из виртуального окружения. Откройте [локальную страницу](http://127.0.0.1:8501), введите имя проверяющего, нажмите **Load sample NDA**, затем **Run two-stage audit**.

### Что проверить в пилоте

В вымышленном NDA заложены три ситуации: право штата Техас вне списка примера, 15 дней для уведомления о непродлении вместо требуемых 60, и одностороннее обязательство о возмещении, скрытое в определениях. Сравните вывод с текстом NDA и отметьте пропуски, неверные замечания и время проверки. Не прикладывайте клиентские документы к публичным отзывам. [Форма обратной связи](https://github.com/amirlan-burkitbayev/VeriPactAI/issues/new?template=pilot.yml).

Интерфейс и тестовый NDA пока на английском. Правила примера рассчитаны на англоязычный документ и не отражают право Казахстана. Качество проверки договоров на русском и скорость обработки за 30 секунд пока не подтверждены. Результат требует проверки юристом.
