# 0.1.0 Preview

ClauseLantern, formerly VeriPact AI, is an MIT-licensed local contract review workspace. This preview includes a sample NDA, editable playbook, source quote checks, Word report export, and a structured pilot feedback form.

The historical [QA results](QA_RESULTS.md) cover the original release. A current real-model benchmark and independent practitioner evaluation are pending. The app is intended for a supervised first pass.
